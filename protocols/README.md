# Original design records

These files preserve the original frozen protocol bytes. Their source and
binary paths describe the historical deployment and are retained as provenance.
Do not use historical commands here to deploy into a new cluster. Use
`docs/paper-experiments.md` and your own explicit deployment configuration.

`prefill.md` and `backend-and-qa.md` match the protocol hashes in the archived
configurations. `shared-budget.md` records the E1–E3 design. Later portable
orchestration and its validation are documented separately; the old records
have not been rewritten as if they described a newly completed reproduction.
